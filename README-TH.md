# LINE Share — แชร์ Flex ต่อกันไม่มีที่สิ้นสุด + เก็บโปรไฟล์ LINE ลง Google Sheet (CeeShop)

## ลิงก์ที่ใช้งาน
| อะไร | ลิงก์ |
|---|---|
| **ลิงก์ส่งให้ลูกค้า** (โชว์ ⭐ แคมเปญหลัก — เลือกในแท็บ "ตั้งค่า" ช่อง B2) | https://liff.line.me/2012679146-P193zTHk |
| ลิงก์แคมเปญเฉพาะ | `https://liff.line.me/2012679146-P193zTHk?c=<id แคมเปญ>` (อยู่คอลัมน์ F ของแท็บ campaigns) |
| ติดตามแหล่งที่มา | ต่อท้าย `&src=facebook` (หรือชื่ออะไรก็ได้) → ไปอยู่คอลัมน์ "แหล่งที่มา" |
| **หน้าแอดมิน** (เปิดใน LINE) | https://liff.line.me/2012679146-P193zTHk?admin=1 |
| รหัสแอดมิน (ใส่ครั้งแรกครั้งเดียว) | ดูใน Apps Script: เลือกฟังก์ชัน `showAdminCode` > เรียกใช้ |

## ทำงานยังไง
1. ส่งลิงก์ให้ลูกค้า → กด → LINE ขอความยินยอม (ชื่อ รูป LINE ID) → กดอนุญาต
2. ระบบตรวจ token กับ LINE ว่าเป็นของจริง → บันทึก/อัปเดตแถวในแท็บ **members**
3. ลูกค้าเห็นการ์ด Flex ที่ใส่ **ชื่อ + รูปของเขาเอง** → กด "แชร์ต่อให้เพื่อน" (เลือกเพื่อน/กลุ่มได้หลายคน)
4. เพื่อนได้การ์ดที่มีลิงก์ส่วนตัวของคนแชร์ (`r=รหัสแนะนำ`) → กด → วนข้อ 1 **ไม่มีที่สิ้นสุด**
5. ระบบรู้ว่า **ใครชวนใคร** · ชั้นที่เท่าไหร่ของสายแชร์ · แต่ละคนชวนสำเร็จกี่คน / แชร์กี่ครั้ง

## ข้อมูลที่เก็บ (Google Sheet "LINE Share DB" บัญชี goimage55)
- **members**: userId, ชื่อ LINE, รูปโปรไฟล์, สเตตัส, อีเมล*, ภาษา, มือถือ (OS), LINE เวอร์ชัน, เปิดจาก (แชทเดี่ยว/กลุ่ม/ภายนอก), รหัสแนะนำ, ผู้ชวน, แคมเปญแรก, แหล่งที่มา, วันลงทะเบียน, เข้าล่าสุด, จำนวนครั้ง, แชร์, ชวนสำเร็จ, ชั้นที่
- **events**: ทุกการเข้า/สมัคร/แชร์ พร้อมเวลา
- **ตั้งค่า**: เลือก ⭐ แคมเปญหลักของลิงก์เปล่า + วิธีใช้สั้นๆ
- **campaigns**: แคมเปญ Flex — A id · B ชื่อ · C altText · D เปิดใช้ · E สถานะ (ระบบเช็ก) · F ลิงก์ · G คนเข้าร่วม · H แชร์ · I สร้าง · J แก้ไข · K หมายเหตุ · **L Flex JSON**
- **admins**: userId ที่เป็นแอดมิน

- **รูปโปรไฟล์อัตโนมัติ** (ทำงานเองทุก 1 นาที): ลิงก์รูปในคอลัมน์ C → **คอลัมน์ V "รูป"** โชว์รูปในช่อง (ฝังในชีต ลิงก์เดิมหมดอายุก็ยังอยู่) + **คอลัมน์ W** ลิงก์ "เปิดไฟล์รูป" = ไฟล์ .jpg ใน Google Drive โฟลเดอร์ **"LINE Share - รูปโปรไฟล์"** (ชื่อไฟล์ `ชื่อ_userId.jpg`)
  - เปลี่ยนรูปโปรไฟล์ใหม่ → แปลงใหม่ให้เอง (ไฟล์เก่าลงถังขยะ) · โหลดไม่ได้ → ช่องขึ้น "โหลดรูปไม่ได้"
  - ตั้งเวลาใหม่/ซ่อม: Apps Script > เลือก `installImageTrigger` > เรียกใช้ · แถวสูงไม่เท่ากัน: เรียกใช้ `tidyImageRows`

\* อีเมล: LINE ให้เฉพาะเมื่อขอสิทธิ์ "Email address permission" ในช่อง LINE Login (แท็บ OpenID Connect > Apply) ผ่านแล้ว + ติ๊ก scope `email` ใน LIFF — ตอนนี้ยังไม่ได้ขอ
เบอร์โทร: LINE ไม่ให้ ต้องทำฟอร์มให้กรอกเอง

## สร้างแคมเปญ — วิธีที่ 1: วางในชีต (แนะนำ)
1. ออกแบบการ์ดใน https://developers.line.biz/flex-simulator/ > **View as JSON** > **Copy**
2. แท็บ **campaigns** > แถวว่าง > (ใส่ชื่อในช่อง B, altText ในช่อง C — ไม่ใส่ก็ได้) > **ดับเบิลคลิกช่อง L** > Ctrl+V > Enter
   - ⚠️ ต้องดับเบิลคลิกก่อนวาง ไม่งั้นชีตแตก JSON ลงหลายแถว (ระบบพยายามรวมกลับให้เอง ถ้าทับแถวอื่นจะขึ้น ❌ ให้กด Ctrl+Z)
   - ระวัง: พิมพ์ในช่อง L เอง ชีตอาจ "เติมอัตโนมัติ" ด้วย JSON ของแถวบน — วางทีเดียวทั้งก้อนจะไม่เจอปัญหานี้
3. รอ 1–2 วินาที (ช้าสุด 1 นาที): ระบบเติม **id, ติ๊กเปิดใช้, สถานะ ✅/⚠️/❌, ลิงก์แคมเปญ (F), วันที่** ให้เอง
4. ลิงก์เปล่าโชว์แคมเปญไหน → แท็บ **ตั้งค่า** ช่อง **B2** เลือก id (หรือหน้าแอดมิน > ปุ่ม "⭐ ตั้งเป็นหลัก")
5. ปิดแคมเปญ = เอาติ๊ก "เปิดใช้" ออก → คนที่กดการ์ดเก่าจะไปแคมเปญหลักแทน (สายแชร์ไม่ขาด) · JSON ❌ ก็ถูกข้ามไปแคมเปญหลักเหมือนกัน
- เคล็ดลับ Simulator: ช่อง url ของรูปพิมพ์ `{{picture}}` ใน Simulator ไม่ได้ → ใส่รูปจริงไปก่อน แล้วค่อยแก้เป็น `{{picture}}` ในชีต
- เครื่องมือ (Apps Script): `setupCampaignTools` = ติดตั้ง/ซ่อมแท็บตั้งค่า + ตัวตรวจ · ตัวตรวจ = ตัวตั้งเวลา "เมื่อแก้ไขชีต" (`onSheetEdit`) + ตัวกวาดสำรองทุก 1 นาที

## สร้างแคมเปญ — วิธีที่ 2: หน้าแอดมิน (ในแอป LINE)
หน้าแอดมิน > แท็บ "แคมเปญ" > สร้างใหม่ / แก้ไข > วาง JSON > **ทดสอบส่ง** (ส่งหาตัวเองดูก่อน) > **บันทึก** · ปุ่ม "⭐ ตั้งเป็นหลัก"

## ทีมงาน — นับยอดแยกรายคน รายเดือน รายปี
| อะไร | ที่ไหน |
|---|---|
| ลิงก์ให้ทีมงานเปิดครั้งแรก (ในแอป LINE) | https://liff.line.me/2012679146-P193zTHk?team=1 |
| รหัสทีมงาน (คนละรหัสกับแอดมิน) | Apps Script > เลือก `showTeamCode` > เรียกใช้ |
| รายชื่อทีมงาน / ถอดออก | แท็บ **ทีมงาน** — ลบแถว = ถอดออก (คำนวณสายใหม่เองภายใน 1 นาที) |
| ตารางเทียบทุกคน | แท็บ **รายงานทีม** — B1 เลือกปี, E1 เลือกตัวเลขรายเดือน (อัปเดตเองทุก 15 นาที / ทันทีเมื่อเปลี่ยน B1, E1) |
| อันดับในแอป LINE | หน้าแอดมิน > แท็บ "ทีมงาน" (เดือนนี้ / ปีนี้ / ทั้งหมด) |

- ทีมงานใส่รหัสครั้งเดียว → หน้าหลักของเขาจะมีการ์ด **"ยอดของคุณ"** (เดือนนี้/ปีนี้/ทั้งหมด + อันดับ) และปุ่มคัดลอก **ลิงก์ทีมงานส่วนตัว** (`?r=รหัสแนะนำ`) โพสต์ที่ไหนก็นับให้เขา
- ทีมงาน **แก้แคมเปญ/ดูข้อมูลคนอื่นไม่ได้** · แอดมิน (รหัส 778583) ทำได้ทุกอย่าง
- ตัวเลข: **แชร์** = กดแชร์สำเร็จ (LINE ไม่บอกจำนวนผู้รับ) · **ชวนตรง** = คนที่กดการ์ด/ลิงก์ของเขาเองแล้วเข้ามา · **สายทั้งหมด** = ทุกคนที่ต่อมาจากเขาทุกชั้น · **ลึกสุด** = สายยาวกี่ชั้น
- กติกาสาย: แต่ละคนนับให้ **ทีมงานที่ใกล้ที่สุดในสายผู้ชวน** คนเดียว (ไม่นับซ้ำ) — ถ้าทีมงาน B อยู่ในสายของทีมงาน A: B นับเป็น 1 คนในสายของ A แต่คนที่ B ชวนต่อจะนับให้ B
- members คอลัมน์ X/Y = "ทีมของ" (ระบบเขียนเอง) · ข้อมูลย้อนหลังนับได้ตั้งแต่ 18 พ.ย. 2569
- เครื่องมือ: `setupTeam` = ติดตั้ง/ซ่อม (แท็บ + รหัส + รายงาน)

## ขีดจำกัดที่ควรรู้
- Apps Script บัญชีฟรี: เรียก LINE ได้ ~20,000 ครั้ง/วัน (1 ครั้งต่อการเปิดหน้า) ทำงานพร้อมกันได้ ~30 คน — ถ้าไวรัลหนักมากอาจช้า
- LINE OA แพ็กเกจฟรี: ส่ง/บรอดแคสต์ได้ราว 300 ข้อความต่อเดือน
- นโยบาย LINE: ห้ามบังคับหรือให้รางวัลแลกการแชร์แบบสแปม และใช้ข้อมูลตามที่แจ้งในหน้านโยบายความเป็นส่วนตัวเท่านั้น (PDPA)
