# LINE Share — แชร์ Flex ต่อกันไม่มีที่สิ้นสุด + เก็บโปรไฟล์ LINE ลง Google Sheet (CeeShop)

## ลิงก์ที่ใช้งาน
| อะไร | ลิงก์ |
|---|---|
| **ลิงก์ส่งให้ลูกค้า** (แคมเปญแรกที่เปิดใช้) | https://liff.line.me/2012679146-P193zTHk |
| ลิงก์แคมเปญเฉพาะ | `https://liff.line.me/2012679146-P193zTHk?c=<id แคมเปญ>` (ดู/คัดลอกในหน้าแอดมิน) |
| ติดตามแหล่งที่มา | ต่อท้าย `&src=facebook` (หรือชื่ออะไรก็ได้) → ไปอยู่คอลัมน์ "แหล่งที่มา" |
| **หน้าแอดมิน** (เปิดใน LINE) | https://liff.line.me/2012679146-P193zTHk?admin=1 |
| รหัสแอดมิน (ใส่ครั้งแรกครั้งเดียว) | ดูใน Apps Script: เลือกฟังก์ชัน `showAdminCode` > เรียกใช้ |

## ทำงานยังไง
1. ส่งลิงก์ให้ลูกค้า → กด → LINE ขอความยินยอม (ชื่อ รูป LINE ID) → กดอนุญาต
2. ระบบตรวจ token กับ LINE ว่าเป็นของจริง → บันทึก/อัปเดตแถวในแท็บ **members**
3. ลูกค้าเห็นการ์ด Flex ที่ใส่ **ชื่อ + รูปของเขาเอง** → กด "แชร์ต่อให้เพื่อน" (เลือกเพื่อน/กลุ่มได้หลายคน)
4. เพื่อนได้การ์ดที่มีลิงก์ส่วนตัวของคนแชร์ (`r=รหัสแนะนำ`) → กด → วนข้อ 1 **ไม่มีที่สิ้นสุด**
5. ระบบรู้ว่า **ใครชวนใคร** · ชั้นที่เท่าไหร่ของสายแชร์ · แต่ละคนชวนสำเร็จกี่คน / แชร์กี่ครั้ง

## ข้อมูลที่เก็บ (Google Sheet "LINE Share DB" บัญชี goimage55)
- **members**: userId, ชื่อ LINE, รูปโปรไฟล์, สเตตัส, อีเมล*, ภาษา, มือถือ (OS), LINE เวอร์ชัน, เปิดจาก (แชทเดี่ยว/กลุ่ม/ภายนอก), รหัสแนะนำ, ผู้ชวน, แคมเปญแรก, แหล่งที่มา, วันลงทะเบียน, เข้าล่าสุด, จำนวนครั้ง, แชร์, ชวนสำเร็จ, ชั้นที่
- **events**: ทุกการเข้า/สมัคร/แชร์ พร้อมเวลา
- **campaigns**: แคมเปญ Flex (แก้ในหน้าแอดมิน — ห้ามแก้ช่อง JSON ในชีตด้วยมือ)
- **admins**: userId ที่เป็นแอดมิน

- **รูปโปรไฟล์อัตโนมัติ** (ทำงานเองทุก 1 นาที): ลิงก์รูปในคอลัมน์ C → **คอลัมน์ V "รูป"** โชว์รูปในช่อง (ฝังในชีต ลิงก์เดิมหมดอายุก็ยังอยู่) + **คอลัมน์ W** ลิงก์ "เปิดไฟล์รูป" = ไฟล์ .jpg ใน Google Drive โฟลเดอร์ **"LINE Share - รูปโปรไฟล์"** (ชื่อไฟล์ `ชื่อ_userId.jpg`)
  - เปลี่ยนรูปโปรไฟล์ใหม่ → แปลงใหม่ให้เอง (ไฟล์เก่าลงถังขยะ) · โหลดไม่ได้ → ช่องขึ้น "โหลดรูปไม่ได้"
  - ตั้งเวลาใหม่/ซ่อม: Apps Script > เลือก `installImageTrigger` > เรียกใช้ · แถวสูงไม่เท่ากัน: เรียกใช้ `tidyImageRows`

\* อีเมล: LINE ให้เฉพาะเมื่อขอสิทธิ์ "Email address permission" ในช่อง LINE Login (แท็บ OpenID Connect > Apply) ผ่านแล้ว + ติ๊ก scope `email` ใน LIFF — ตอนนี้ยังไม่ได้ขอ
เบอร์โทร: LINE ไม่ให้ ต้องทำฟอร์มให้กรอกเอง

## สร้าง/แก้แคมเปญ (หน้าแอดมิน)
1. ออกแบบการ์ดใน https://developers.line.biz/flex-simulator/ > View as JSON > คัดลอก
2. หน้าแอดมิน > แท็บ "แคมเปญ" > สร้างใหม่ / แก้ไข > วาง JSON > **ทดสอบส่ง** > **บันทึก**
3. ตัวแปรใส่ในข้อความ/รูป/ลิงก์ของการ์ดได้:

| ตัวแปร | แทนด้วย |
|---|---|
| `{{name}}` | ชื่อ LINE ของคนที่แชร์ |
| `{{picture}}` | รูปโปรไฟล์คนที่แชร์ (ใช้ใน image url) |
| `{{shareUrl}}` | ลิงก์แชร์ต่อของคนนั้น (ใส่ในปุ่ม) — **ถ้าไม่ใส่ ระบบเติมปุ่ม "แชร์ต่อให้เพื่อน" ให้เอง** |
| `{{members}}` | จำนวนคนที่ร่วมแคมเปญแล้ว |
| `{{invited}}` | จำนวนคนที่ผู้แชร์ชวนได้ |
| `{{campaign}}` `{{date}}` | ชื่อแคมเปญ / วันที่ |

แคมเปญตัวอย่าง `c1` ลิงก์ปุ่ม "เปิดดู" ไปที่ develop-marketing.com — แก้เป็นลิงก์สินค้า/เพจ CeeShop ก่อนใช้จริง

## ขีดจำกัดที่ควรรู้
- Apps Script บัญชีฟรี: เรียก LINE ได้ ~20,000 ครั้ง/วัน (1 ครั้งต่อการเปิดหน้า) ทำงานพร้อมกันได้ ~30 คน — ถ้าไวรัลหนักมากอาจช้า
- LINE OA แพ็กเกจฟรี: ส่ง/บรอดแคสต์ได้ราว 300 ข้อความต่อเดือน
- นโยบาย LINE: ห้ามบังคับหรือให้รางวัลแลกการแชร์แบบสแปม และใช้ข้อมูลตามที่แจ้งในหน้านโยบายความเป็นส่วนตัวเท่านั้น (PDPA)
